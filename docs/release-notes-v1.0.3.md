# v1.0.3 · 白天模式配色修复

这是一个小修复版：白天模式下看板顶部那四个统计按钮（课程 / 文件 / 10 天内截止 / 未提交）和热力图格子里的数字几乎看不见 —— 现在正常了。

## 修了什么

| 问题 | 原来 | 现在 |
| --- | --- | --- |
| 看板四个统计按钮（白天模式） | 白字配近白底，对比度 **1.07:1**，几乎隐身 | 跟着主题走，6.7:1 |
| 热力图格子里的数字 | 浅色格上仍是白字，**1.49:1** | 浅色格深字、深色格白字 |
| 深色模式按钮 | 白字配浅紫，**2.92:1** | 改用更深的按钮底色，5.0:1 |
| 「未提交」标签 / 次要文字 | 3.07:1 / 4.3:1 | 5.0:1 / 5.1:1 |

根因是那四个按钮沿用了一套「为紫色头部设计」的样式（白字 + 半透明白底），但它们其实渲染在页面背景上 —— 深色模式看起来正常，所以之前一直没暴露。我用对比度扫描把同类问题一起找了出来：**白天/深色 × 看板/日历/设置 六种组合，低于 WCAG AA（4.5:1）的元素现在是 0 个**。

## 顺带清理

- `/api/health` 不再向未鉴权的局域网请求返回版本号、局域网开关与证书指纹（只回 `{"ok":true}`），离线探测与 `doctor` 不受影响
- **Service Worker 缓存版本改为按 `index.html` 内容哈希自动生成**：前端一改就必然触发更新，以后不会再出现「我明明改了，手机桌面点开还是旧样式」；联网加载时也会顺手刷新离线副本
- 重新截取白天模式截图，文档配色与线上一致
