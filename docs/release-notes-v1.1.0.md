# v1.1.0 · 高频盯防（随堂 quiz）

有些课会突然放出很短的随堂测验，甚至课上才说 —— 每天两次的定时同步根本抓不到。这一版加的就是它：**在你指定的时间窗口里，用更高的频率盯着 Canvas，一有动静立刻强提醒**。

## 怎么用（四步）

1. 打开看板 →「设置 → 高频盯防」→「＋ 新建规则」
2. 起个名字（例如 `6018 随堂 quiz`），勾上要盯的课
3. 勾星期（不勾 = 每天），填时段（留空 = 全天）；想只盯某几天就再填日期区间
4. 选扫描间隔（默认 3 分钟）与重复提醒策略，勾上「桌面通知 / 提示音 / 飞书推送」→ 保存

保存后看板顶部会出现 🟢 **盯防中**，显示当前生效的规则与上次扫描时间。

## 什么情况会提醒你

| 情况 | 说明 |
| --- | --- |
| 新增作业 / 测验 / 公告 | 课程里出现之前没见过的条目 |
| **截止时间变动** | 从「暂无截止」变成有截止，或截止时间被改 —— 随堂 quiz 最典型的信号 |

> 第一次扫描只建立基线，不会把历史作业全部推一遍；但最近 1 小时内新建的内容仍会提醒，所以刚配好就赶上的随堂 quiz 也不会漏。

## 提醒有多「强」

- **桌面通知**：macOS 带提示音，Windows 原生 Toast
- **飞书推送**：手机上直接收到消息（这也是目前最能「随时随地」提醒你的渠道）
- **重复提醒**：命中后如果一直没确认，按你设的间隔再推（默认 5 分钟一次、最多 2 次），直到你在看板上点「知道了」

两个渠道都能在规则里单独关掉；看板顶部的红色横幅会一直保留未确认的命中。

## 对 Canvas 友好

- **只有窗口内才发请求**：每门课每轮 2~3 个轻量调用，默认 3 分钟一轮；不在窗口内时**零请求**
- 间隔下限 1 分钟，避免被 Canvas 限流；命中判定完全靠本地比对，**不消耗 DeepSeek 额度**
- 扫描器跑在常驻的 Web 服务进程里：macOS / Windows / Linux 都一样，**不需要新增任何系统计划任务**

## 命令行

    node cli.mjs watch              # 立刻扫一次（窗口外需加 --force）
    node cli.mjs watch --status     # 只看规则状态

## 下载哪个？

| 你的系统 | 下载 | 安装 |
| --- | --- | --- |
| **Windows** | `canvas-hub-1.1.0-windows.zip` | 解压后：`powershell -ExecutionPolicy Bypass -File install.ps1` |
| **macOS / Linux** | `canvas-hub-1.1.0-macos-linux.tar.gz` | `tar -xzf ... && cd canvas-hub-1.1.0 && bash install.sh` |

## 升级

    cd canvas-hub && git pull

后端重新加载即可生效（macOS：`launchctl kickstart -k gui/$(id -u)/com.canvashub.web`；Windows：在任务计划程序里运行 `CanvasHub-Web`）。
